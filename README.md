# valmirSilva-academic-portfolio
## 📖 About
This repository contains my personal academic portfolio website, developed as part of the *Fundamentals of Web Programming* course.  
The main goal of this project is to apply and practice the knowledge acquired during the discipline, showcasing my projects, ideas, and web development skills.

## 🚀 Features
- Responsive layout with HTML and CSS
- Dark mode toggle
- Portfolio sections: About Me, Education, Projects, and Contact
- Contact form simulation with JavaScript

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
